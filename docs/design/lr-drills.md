# LR drills: product review (29 Oct 2026)

A product look at the three LR drills (F83 to F85) after the first build, before going further. Decision D48 in `docs/analyze.md`.

## Who and what for

A CAT student practising DILR on this site. Their aim is to pick two or three sets in 40 minutes and get them right. Three things lose them marks after the set is understood: reading a clue wrongly, answering "must be true" from one case, and starting with a clue that opens too many cases. The drills train each one on its own, in a few minutes.

## What the first build gets wrong

Opened cold, as a student meets them:

| Problem | Where | Effect |
|---|---|---|
| No "how it works": the student must guess what to tap and why | all three | the first run is spent working out the screen, not the skill |
| Must, could, cannot shows seatings with no story and no clues ("Clue 3 is left out", but not what clue 3 says) | must-could | the seatings look arbitrary; the student cannot check them |
| A round table drawn as a list of seats | must-could | "opposite" and "second to the right" have to be pictured from a sentence |
| After checking, ✓ and ✗ per seating but no sentence saying why | must-could, first move | a wrong answer teaches nothing |
| "176 ways" with no meaning given | first move | the number is noise until "ways" is explained |
| Drills are reached only from a section on the practice page; a mistake in a set never points to one, and a drill never leads back to the question | all | drills feel like a side game, and the student does not know when to use them |

## Principles

1. **Self-explaining on first use.** Each drill opens with a short "how it works" and one worked example; it folds away after the first run and can be opened again.
2. **Show the set.** Any drill on a set shows the story and clues; a left-out clue is shown crossed out.
3. **Pictures, not lists, for tables.** A round table is drawn round. What changes between seatings is marked.
4. **Every answer explained in a sentence**, worked out by code from the same cases, never typed.
5. **Reached from the student's own mistake.** The set review suggests the drill that trains what the post-mortem says went wrong, on the same set where possible, and the drill leads back to the set.

## The loop

1. The student solves a set and answers the two-minute post-mortem.
2. The review's next-step card names the drill for what went wrong:
   - **The clue that opened the set** → First move on this set: "You opened with clue 7, which leaves 176 ways; clue 12 leaves 1."
   - **Misread a clue** → Clue translator on that kind of clue ("between", "only if"…).
   - **Missed a case** → Must, could, cannot on this set, when there is one.
3. The drill ends with "Back to the set" (its review or a retake).
4. The question itself is already in the redo queue, so it comes back on days 1, 3 and 7.
5. Progress shows the weakest kind of clue with a link to practise exactly that kind.

## What stays

- The drills section on the DILR practice page, for practice on its own.
- Answers worked out by the solver (D47).
- The clue translator's practice clues: our sets have almost no "only if", "unless" or "either or" clues, so those must be written. Moving seating items to real set clues is later work.

## Not now

- Suggesting drills on Today: wait until students use the review suggestions.
- Models for the other set types (tournaments, caselets): each needs its own expressions.
